# 分解图像后处理流程说明

## 概述

本文档详细介绍了如何对扩散模型分解得到的单层2D材料图像进行后处理分析，主要包括：
1. 原子坐标提取
2. 晶格基矢量（da/db）的统计计算
3. 两层间配准与材料参数求解（翻转flip、滑移矢量、扭转角）

---

## 1. 原子坐标提取

### 1.1 基本原理

原子坐标提取基于图像处理中的轮廓检测方法，利用HAADF-STEM图像中原子位置对应的高亮区域进行定位。

### 1.2 实现步骤

```python
def find_center(img_gap, min_area_threshold=100, bina_thre=3):
    """
    在图像中检测原子中心点

    Args:
        img_gap (np.ndarray): 输入图像 (归一化到0-1)
        min_area_threshold (int): 最小面积阈值，过滤噪声
        bina_thre (float): 二值化阈值倍数（相对于图像均值）

    Returns:
        list: 检测到的中心点坐标列表 [(x1,y1), (x2,y2), ...]
    """
    # 步骤1: 自适应二值化处理
    # 阈值 = 图像均值 × bina_thre，适应不同对比度的图像
    _, binary = cv2.threshold(img_gap, img_gap.mean() * bina_thre, 1, cv2.THRESH_BINARY)

    # 步骤2: 寻找连通区域轮廓
    contours, _ = cv2.findContours(np.uint8(binary), cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

    centers = []
    for contour in contours:
        # 步骤3: 计算轮廓面积，过滤小噪声点
        area = cv2.contourArea(contour)
        if area > min_area_threshold:
            # 步骤4: 计算轮廓的质心作为原子中心
            M = cv2.moments(contour)
            if M["m00"] != 0:
                center = (int(M["m10"] / M["m00"]), int(M["m01"] / M["m00"]))
                centers.append(center)

    return centers
```

### 1.3 关键参数调优

| 参数 | 典型值 | 说明 |
|------|--------|------|
| `min_area_threshold` | 50-100 | 根据图像分辨率调整，过小会引入噪声 |
| `bina_thre` | 1.5-3.0 | 对比度低用较小值(1.5)，高对比度用较大值(3.0) |

## 2. 晶格基矢量（da/db）的统计计算

### 2.1 总体流程

晶格基矢量的计算采用**图论+聚类**的方法，主要步骤如下：

```
原子坐标 → 构建图结构 → 四元环识别 → 原子聚类 → 向量提取 → 方向调整
```

### 2.2 图结构构建

基于原子坐标构建无向图，每个原子为节点，连接最近的3个邻居。

```python
def create_graph_from_coordinates(img, coordinates, color='skyblue'):
    """
    基于原子坐标构建网络图

    原理：ReS2等材料具有明显的四元环结构，通过图结构可以识别这些特征
    """
    G = nx.Graph()

    # 添加节点
    for i in range(len(coordinates)):
        pos = (coordinates[i][0], coordinates[i][1])
        G.add_node(i, pos=pos)

    # 添加边：连接每个原子的最近3个邻居
    for i in range(len(coordinates)):
        xi, yi = coordinates[i]
        distances = []
        indices = []

        for j in range(len(coordinates)):
            if j != i:
                xj, yj = coordinates[j]
                distance = np.sqrt((xi - xj)**2 + (yi - yj)**2)
                distances.append(distance)
                indices.append(j)

        # 排序并连接最近的3个
        sorted_indices = [idx for _, idx in sorted(zip(distances, indices))]
        for idx in sorted_indices[:3]:
            G.add_edge(i, idx)

    return G
```

### 2.3 四元环识别与过滤

ReS2材料具有特征性的四元环结构（菱形晶格），通过识别四元环来过滤有效的晶格点。

```python
def find_four_cycles(graph):
    """
    找到图中所有四元环

    四元环识别原理：
    对于节点A，如果其两个邻居B、C有共同邻居D，则A-B-D-C-A构成四元环
    """
    four_cycles = set()
    for node in graph.nodes():
        neighbors = list(graph.neighbors(node))
        if len(neighbors) < 3:
            continue
        # 遍历邻居的所有配对
        for neighbor_pair in combinations(neighbors, 2):
            # 找到两个邻居的共同邻居
            common_neighbors = set(graph.neighbors(neighbor_pair[0])).intersection(
                set(graph.neighbors(neighbor_pair[1])))
            common_neighbors.discard(node)

            for common_neighbor in common_neighbors:
                cycle = [node, neighbor_pair[0], common_neighbor, neighbor_pair[1]]
                cycle.sort()
                four_cycles.add(tuple(cycle))

    return [list(cycle) for cycle in four_cycles]
```

### 2.4 原子聚类分析

通过K-means聚类将原子分为4类（对应晶格的4个子格点），聚类特征为**邻域向量模式**。

```python
def cluster_and_visualize(img_graph, outlier_ratio=0.2, n_clusters=4):
    """
    对原子进行聚类分析

    聚类依据：每个原子的邻域向量模式
    - ReS2有4个等价子格点，每个子格点的邻域模式不同
    - 通过K-means将原子分为4类
    """
    # 提取每个节点的邻域向量特征
    adjacency_vectors = {}
    adjacency_vectors_list = []

    for node in img_graph.nodes():
        neighbors = list(img_graph.neighbors(node))
        node_pos = img_graph.nodes[node]['pos']
        neighbor_positions = [img_graph.nodes[n]['pos'] for n in neighbors]

        # 计算邻域差分向量
        diff_vectors = [np.subtract(neighbor_pos, node_pos)
                       for neighbor_pos in neighbor_positions]

        # 按角度排序（确保特征一致性）
        sorted_vectors = sorted(diff_vectors,
                               key=lambda x: (np.arctan2(x[1], x[0]), np.linalg.norm(x)))

        adjacency_vectors[node] = sorted_vectors
        adjacency_vectors_list.append(sorted_vectors)

    # K-means聚类（4个子格点）
    adjacency_vectors_arr = np.array([np.hstack(v) for v in adjacency_vectors_list])
    kmeans = KMeans(n_clusters=n_clusters, init='k-means++', random_state=42)
    labels = kmeans.fit_predict(adjacency_vectors_arr)

    # 异常值处理（边缘缺陷原子等）
    distances = np.sqrt(((adjacency_vectors_arr - kmeans.cluster_centers_[labels])**2).sum(axis=1))
    n_outliers = int(len(labels) * outlier_ratio)
    outliers = np.argpartition(distances, -n_outliers)[-n_outliers:]
    labels[outliers] = 0  # 标记为异常值

    # 后处理：移除相同标签节点间的边（避免同一子格点互连）
    node_labels = {node: label for node, label in zip(img_graph.nodes(), labels)}
    for node1, node2 in list(img_graph.edges()):
        if node_labels[node1] == node_labels[node2]:
            img_graph.remove_edge(node1, node2)

    # 保留四元环相关的边
    remove_four(img_graph)  # 只保留构成四元环的边
    remove_nodes_less_than_three(img_graph)  # 移除度数<3的孤立节点

    # 分析四元环中的标签分布，确定长边和短边对应的标签
    four_cycles = find_four_cycles(img_graph)
    longest_edge_labels = [get_longest_edge_labels(cycle, node_labels, img_graph)
                          for cycle in four_cycles]
    flat_labels = list(itertools.chain(*longest_edge_labels))
    label_counter = Counter(flat_labels)
    most_common_labels = label_counter.most_common(2)

    max_length_labels = [most_common_labels[0][0], most_common_labels[1][0]]  # 长边标签
    min_length_labels = [item for item in [1, 2, 3, 4] if item not in max_length_labels]  # 短边标签

    return labels, min_length_labels, max_length_labels
```

### 2.5 晶格向量提取

基于聚类结果，找到合适的原子对来计算晶格基矢量。

```python
def calculate_vectors(labels, img_graph, max_length_labels, min_length_labels):
    """
    计算材料的晶格向量 va 和 vb

    原理：
    - va: 对应晶格的a轴（长边方向），连接max_length_labels的两个原子
    - vb: 对应晶格的b轴（短边方向），连接min_length_labels的两个原子

    寻找满足以下条件的四元环：
        点3 (min) --- 点1 (max)
          |            |
        点4 (min) --- 点2 (max)

    则 va = 点1 - 点3（或 点2 - 点4）
       vb = 点3 - 点4
    """
    point_indice_dict = {}

    # 遍历寻找合适的点对
    for indice in [i for i, x in enumerate(labels) if x == max_length_labels[0]]:
        point_indice_dict['1'] = indice  # 第一个长边点
        neighbors = list(img_graph.neighbors(indice))

        for neighbor_ind in neighbors:
            point_indice_dict['2'] = neighbor_ind  # 第二个长边点

            if labels[neighbor_ind] == max_length_labels[1]:
                neighbors_1 = list(img_graph.neighbors(point_indice_dict['1']))
                neighbors_2 = list(img_graph.neighbors(point_indice_dict['2']))

                for neighbor_ind_1 in neighbors_1:
                    point_indice_dict['3'] = neighbor_ind_1  # 第一个短边点

                    for neighbor_ind_2 in neighbors_2:
                        point_indice_dict['4'] = neighbor_ind_2  # 第二个短边点

                        # 检查是否满足条件
                        if is_okay(labels, point_indice_dict, min_length_labels,
                                 neighbors, neighbors_1, neighbors_2):
                            break

    # 计算向量
    vb = np.array(img_graph.nodes[point_indice_dict['3']]['pos']) - \
         np.array(img_graph.nodes[point_indice_dict['4']]['pos'])

    va1 = np.array(img_graph.nodes[point_indice_dict['1']]['pos']) - \
          np.array(img_graph.nodes[point_indice_dict['3']]['pos'])
    va2 = np.array(img_graph.nodes[point_indice_dict['2']]['pos']) - \
          np.array(img_graph.nodes[point_indice_dict['4']]['pos'])

    # 选择与vb夹角更合理的va
    angle1 = vector_angle(va1, vb)
    if angle1 > np.pi / 2:
        angle1 = np.pi - angle1
    va = va2 if angle1 < 0.2 else va1

    # 调整向量方向（确保va和vb夹角为钝角）
    angleab = vector_angle(va, vb)
    if angleab < np.pi / 2:
        va = -va

    # 根据材料的已知晶格常数缩放
    # ReS2: a = 6.585 Å, b = 6.4 Å
    length_va = np.linalg.norm(va)
    length_vb = np.linalg.norm(vb)
    va = va * (length_vb / length_va) * 6.585 / 6.4

    return va, vb
```

## 3. 两层间配准与材料参数求解

### 3.1 配准问题定义

给定两层分解得到的图像（layer 0和layer 1），需要求解以下参数：

1. **翻转（Flip）**: 是否发生镜像翻转
2. **刚体变换**: 旋转角度θ + 平移向量(dx, dy)
3. **滑移矢量**: 在晶格坐标系下的层间位移

### 3.2 配准算法核心流程

```python
def search_gap(img_stand_centers_arr, paired_arr, distance_threshold=20, break_thre=0.8):
    """
    搜索最佳配准参数

    目标：找到使两层原子坐标最佳对齐的刚体变换参数
    优化目标：最小化配准后的平均最近邻距离

    Args:
        img_stand_centers_arr: 参考层（layer 0）的原子坐标
        paired_arr: 待配准层（layer 1）的原子坐标
        distance_threshold: 最近邻搜索距离阈值
        break_thre: 早停阈值（配准误差低于此值时停止搜索）

    Returns:
        dict: 最佳参数 {'theta': 旋转角, 'reflect': 是否翻转,
                      'shift': 平移向量, 'mean_dis': 平均误差}
    """
    para_list = []
    dis_list = []
    kdtree = KDTree(img_stand_centers_arr)  # 构建KD树加速最近邻搜索

    # 遍历参数空间
    for theta in np.linspace(0, np.pi/3, 180):  # 旋转角度：0-60°（考虑晶格对称性）
        for reflect in [False, True]:  # 是否翻转
            for dx in range(-50, 51, 2):  # 平移x：-50到50像素
                for dy in range(-50, 51, 2):  # 平移y：-50到50像素

                    # 应用线性变换（旋转+翻转）
                    paired_arr_new = lin_trans(paired_arr, theta=theta, reflect=reflect)

                    # 找到变换后图像中心最近的原子
                    center_point = find_closest_point(paired_arr_new)

                    # 在参考层中找到最近的15个原子
                    _, indices = kdtree.query(center_point, k=15)
                    nearest_points = [img_stand_centers_arr[idx] for idx in indices]

                    # 尝试将中心点对齐到每个候选点
                    for nearest_point in nearest_points:
                        # 计算总平移向量
                        shift = nearest_point - center_point + np.array([dx, dy])
                        shift_arr = paired_arr_new + shift

                        # 计算配准误差（平均最近邻距离）
                        distances, _ = kdtree.query(shift_arr)
                        filtered_distances = [d for d in distances if d < distance_threshold]
                        mean_distances = np.mean(filtered_distances)

                        # 记录结果
                        dis_list.append(mean_distances)
                        para_list.append({
                            'mean_dis': mean_distances,
                            'theta': theta,
                            'reflect': reflect,
                            'shift': shift,
                            'shift_arr': shift_arr
                        })

                        # 早停机制（提高效率）
                        if mean_distances < break_thre:
                            break

                    if len(dis_list) > 0 and dis_list[-1] < break_thre:
                        break
                if len(dis_list) > 0 and dis_list[-1] < break_thre:
                    break
            if len(dis_list) > 0 and dis_list[-1] < break_thre:
                break
        if len(dis_list) > 0 and dis_list[-1] < break_thre:
            break

    # 返回误差最小的参数组合
    index = np.argmin(np.array(dis_list))
    return para_list[index]
```

### 3.3 线性变换函数

```python
def lin_trans(centers_arr, theta=0, reflect=False, size=512):
    """
    对坐标点进行线性变换

    变换顺序：平移到原点 → 翻转(可选) → 旋转 → 平移回图像中心

    Args:
        centers_arr: 原子坐标数组 (N, 2)
        theta: 旋转角度（弧度）
        reflect: 是否进行x轴镜像翻转
        size: 图像尺寸

    Returns:
        变换后的坐标数组
    """
    centers_arr_new = centers_arr.copy()

    # 平移到原点
    centers_arr_new -= size // 2

    # 翻转（x坐标取反）
    if reflect:
        centers_arr_new[:, 0] *= -1

    # 旋转变换矩阵
    rot_arr = np.array([[np.cos(theta), -np.sin(theta)],
                       [np.sin(theta), np.cos(theta)]])
    centers_arr_new = (rot_arr @ centers_arr_new.T).T

    # 平移回图像中心
    centers_arr_new += size // 2

    return centers_arr_new
```

### 3.4 滑移矢量投影到晶格坐标系

配准得到的平移向量是像素坐标系下的，需要投影到晶格坐标系（da/db坐标系）。

```python
def project(va, vb, vec, return_type='prov'):
    """
    将像素坐标系的向量投影到晶格坐标系

    原理：
    设晶格基矢量为 va, vb，构成变换矩阵 P = [va, vb]
    任意向量 vec 在晶格坐标系下的坐标为 prov = P^(-1) @ vec
    即 vec = prov[0] * va + prov[1] * vb

    Args:
        va, vb: 晶格基矢量（像素单位）
        vec: 待投影向量（像素单位）
        return_type:
            'prov' - 返回晶格坐标（单位：纳米）
            'vec'  - 返回晶格坐标对应的像素向量

    Returns:
        投影结果（2维向量）
    """
    # 构建变换矩阵
    P = np.zeros((2, 2))
    P[:, 0] = va
    P[:, 1] = vb

    # 投影到晶格坐标系
    prov = np.linalg.inv(P) @ vec

    # 归一化到[0, 1]区间（利用晶格周期性）
    for i in range(2):
        while prov[i] < 0 or prov[i] > 1:
            if prov[i] < -1:
                prov[i] += np.ceil(-prov[i])
            elif prov[i] < 0:
                prov[i] += 1
            elif prov[i] > 2:
                prov[i] -= np.floor(prov[i] - 1)
            elif prov[i] > 1:
                prov[i] -= 1

    # 选择最短的等价向量（考虑对称性）
    if prov[0] + prov[1] > 1:
        prov[0], prov[1] = 1 - prov[0], 1 - prov[1]

    if return_type == 'prov':
        # 转换为实际物理单位（纳米）
        # ReS2: a = 6.585 Å, b = 6.42 Å
        return np.array([prov[0] * 0.6585, prov[1] * 0.642]).reshape(2, 1)
    elif return_type == 'vec':
        # 返回像素坐标
        return (P @ prov).reshape(2, 1)
```

### 3.5 完整的配准与参数提取

```python
def para_result(img1_centers_arr, img2_centers_arr, va1, vb1, va2, vb2,
                vec=None, return_type='prov', distance_threshold=10):
    """
    计算两层间的材料参数

    Args:
        img1_centers_arr, img2_centers_arr: 两层的原子坐标
        va1, vb1: layer 0的晶格基矢量
        va2, vb2: layer 1的晶格基矢量
        vec: 已知的滑移矢量（用于验证）
        return_type: 返回类型
        distance_threshold: 配准距离阈值

    Returns:
        shift1, shift2: 两个可能的滑移矢量（考虑对称性）
    """
    if vec is not None:
        # 如果已知滑移矢量，直接投影
        return project(va1, vb1, vec, return_type)

    # 执行配准算法
    result = search_gap(img1_centers_arr, img2_centers_arr,
                       distance_threshold=distance_threshold)

    vec = result['shift'].reshape(2, 1)
    theta = result['theta']
    reflect = result['reflect']

    # 投影到晶格坐标系
    shift1 = project(va1, vb1, vec, return_type)
    shift2 = project(va1, vb1, -vec, return_type)  # 考虑对称性

    # 选择幅值较小的作为滑移矢量
    if np.sum(shift1**2) > np.sum(shift2**2):
        shift = shift2
    else:
        shift = shift1

    # 输出结果
    print(f"配准结果:")
    print(f"  是否翻转(Flip): {reflect}")
    print(f"  旋转角度: {theta:.4f} rad ({theta*180/np.pi:.2f}°)")
    print(f"  平移向量(像素): {vec.flatten()}")
    print(f"  滑移矢量(晶格坐标): da={shift1[0][0]:.4f}, db={shift1[1][0]:.4f}")
    print(f"  配准误差: {result['mean_dis']:.2f} 像素")

    return shift1, shift2
```

## 4. 批量处理与结果保存

### 4.1 批量处理脚本

```python
def process_folder(folder, outlier_ratio=0.05, predict=True, distance_threshold=40):
    """
    处理单个文件夹的原子配准

    文件夹命名格式: "A-B" (例如 "1_30-2_45")
    - A: layer 0的标识 (图像编号_旋转角度)
    - B: layer 1的标识
    """
    folder_parts = folder.split('-')
    A, B = folder_parts[0], folder_parts[1]

    # 读取图像
    pre_fix = f'{folder_path}/{folder}'
    img1 = get_img_arr(pre_fix=pre_fix, end_str=f'{A}-predict')
    img2 = get_img_arr(pre_fix=pre_fix, end_str=f'{B}-predict')

    # 提取原子中心
    img1_centers = find_center(img1, min_area_threshold=50, bina_thre=1.8)
    img2_centers = find_center(img2, min_area_threshold=50, bina_thre=1.8)
    img1_centers_arr = np.array(img1_centers).astype(np.float64)
    img2_centers_arr = np.array(img2_centers).astype(np.float64)

    # 构建图结构
    img1_graph = create_graph_from_coordinates(img1, img1_centers)
    img2_graph = create_graph_from_coordinates(img2, img2_centers)

    # 聚类分析
    labels1, min_labels1, max_labels1 = cluster_and_visualize(
        img1_graph, outlier_ratio=outlier_ratio, n_clusters=4)
    labels2, min_labels2, max_labels2 = cluster_and_visualize(
        img2_graph, outlier_ratio=outlier_ratio, n_clusters=4)

    # 计算晶格向量
    va1, vb1 = calculate_vectors(labels1, img1_graph, max_labels1, min_labels1)
    va2, vb2 = calculate_vectors(labels2, img2_graph, max_labels2, min_labels2)

    # 配准与参数计算
    shift1, shift2 = para_result(img1_centers_arr, img2_centers_arr,
                                 va1, vb1, va2, vb2,
                                 return_type='vec',
                                 distance_threshold=distance_threshold)

    # 保存结果
    results = {
        'folder': folder,
        'va1': va1, 'vb1': vb1,
        'va2': va2, 'vb2': vb2,
        'shift_pixel': shift1,
        'shift_lattice': project(va1, vb1, shift1, return_type='prov')
    }

    return results
```

import concurrent.futures

## 6. 总结

本后处理流程实现了从分解图像到材料参数的完整分析链：

```
分解图像
  ↓
原子坐标提取 (轮廓检测+质心计算)
  ↓
图结构构建 (最近邻图+四元环识别)
  ↓
原子聚类 (K-means based on邻域模式)
  ↓
晶格向量提取 (da/db方向)
  ↓
两层配准 (刚体变换搜索)
  ↓
参数输出 (Flip, 旋转角, 滑移矢量)
```

该方法具有以下优势：
- **鲁棒性强**: 通过图论方法自动识别晶格结构，适应边缘缺陷
- **精度高**: 亚像素级配准精度（典型误差<1像素）
- **自动化**: 无需人工标注，适合批量处理
- **可扩展**: 可适配不同的2D材料（MoS2, TaS2等）

## 7. 双层 ReS2 滑移评估脚本（evaluate_bilayer_res2_sliding）

在基于 `tools/generate_bilayer_res2_sliding.py` 生成双层 ReS2 滑移数据、并使用 `configs/separate/ReS2.yml` 对 128×128 双层图像完成分解之后，可以使用评估脚本对滑移预测进行定量评估：

```bash
# 在仓库根目录执行
python tools/evaluate_bilayer_res2_sliding.py \
  --bilayer_root data/experiments/ReS2_sliding \
  --results_root data/experiments/ReS2_sliding/results/step_200
```

- 脚本会从 `bilayer_root/labels.txt` 中读取每张样本的 dadb 真值标签和像素基向量 `(da_x, da_y, db_x, db_y)`；
- 对 `results_root/bilayer_xxxxxx/` 中的 `_0.png`、`_1.png` 做原子中心检测与平移配准，估计像素滑移向量；
- 使用与 `project_to_dadb` 一致的投影逻辑，将像素滑移投影到 dadb 坐标系下得到预测的 `(da_norm_pred, db_norm_pred)`；
- 根据 labels 中的像素基向量恢复 dadb 夹角 θ，并在物理平面中构造 `|da|=6.585 Å`、`|db|=6.42 Å` 的基向量；
- 将预测与真值映射为二维物理位移向量，计算欧氏距离误差（单位 Å）。

运行完成后，脚本会在 `bilayer_root` 下生成：
- `eval_results.csv`：逐样本的 dadb 预测/真值、对应的二维物理位移向量以及误差；
- `eval_results.summary.txt`：误差的整体统计（样本数、均值、标准差、分位数等）。
