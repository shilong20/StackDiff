# Example Data

This directory contains small examples copied from the development workspace
for release smoke tests. It is not the full training or evaluation dataset.

- `training/`: representative training-style images and masks.
- `slip_psnr24/`: small bilayer slip examples, with ReS2 examples selected from
  a PSNR=24 noise-vs-GT set and other materials selected from existing slip
  experiment folders when PSNR=24 variants were not available locally.
